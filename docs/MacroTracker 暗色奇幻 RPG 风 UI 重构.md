# MacroTracker 暗色奇幻 RPG 风 UI 重构

Oct 18, 2026 · @JD

## 背景与目标

决定：全站统一为暗色奇幻 RPG 风，以成就页现有的徽章世界观为基准。

现状是全站并存两套视觉语言：

- **成就页**：3D RPG 吉祥物插画、铜银金钻四档稀有度、金属光泽与光晕、弹簧动画、解锁爆发动效，已经有游戏感。
- **其他页面**：体育记分牌风格，浅色 `--paper` 底、钴蓝主色、斜体号码数字、1px 细边框白卡片、扁平按钮。

目标：

- 先统一组件层（卡片、按钮、分段控件、输入框、进度条），让五个页面一起换装。
- 再把每个页面映射成对应的游戏概念，只换皮，不新增数据、不改数据库。
- 等级 / 经验值等新玩法放到最后单独评估。

## 设计方向

基调是夜晚的地牢冒险日志：深色石材底、羊皮纸色文字、黄铜描边，和徽章插画的暗色背景一致。

### 配色 token（初稿，全部待对比度与色盲校验）

| token | 现值 | 提议值 | 用途 |
| --- | --- | --- | --- |
| `--paper` | #EDF0F5 | #110E18 | 页面背景，夜空紫黑 |
| `--surface` | #FFFFFF | #1D1827 | 卡片底，暗石 |
| `--line` | #DDE1EA | #4A3B2A | 卡片边框，暗黄铜 |
| `--ink` | #0D1530 | #F1E6CF | 正文，羊皮纸 |
| `--muted` | #596179 | #A89C86 | 次要文字 |
| 新增 `--gold` | 无 | #E8B04B | 主强调色：主按钮、选中态、标题缎带 |
| `--cobalt` | #1C2FD1 | #6C86FF | 降为“奥术蓝”，用于链接与焦点环 |

- 宏量色直接复用现有的“钴蓝记分牌”版本（`--protein` #FF6E8A、`--carbs` #F5B32E、`--fat` #2FCFA8），它们本来就是为深底校验的。
- `--ok` / `--over` / `--under` 及其 `-bg` 需要重新调成深底版本。
- 徽章四档 `--bronze` / `--silver` / `--gold` / `--diamond` 的底色 `-bg` 改为深色微光，金属色本身保留。

### 材质

- **卡片**：2px 黄铜边框 + 顶部 1px 内高光 + 底部实色阴影（`0 4px 0`），做出厚度。
- **标题**：`.panel-head` 改为缎带横幅，左右带小角饰。
- **按钮**：金色 3D 按钮，`:active` 时 `translateY(4px)` 并去掉底部阴影。
- **进度条**：加粗、分段刻度、复用徽章的光泽扫过效果。
- 纹理只用 CSS 渐变和阴影，不引入位图素材。

### 字体

- 标题继续用 Noto Sans SC 900，数字继续用 Archivo 斜体窄体 `.num`。
- 不用像素字体：中文像素字体文件大，小字号难读。
- 可选：品牌标和大数字试用一款古典拉丁衬线体（如 Cinzel），只用于拉丁字符。

### 动效原则

- 先复用现有的 `--ease-out`、`--ease-spring`、`pageIn`、`panelIn`、`chipIn`、`bump`、`tierPop`、`replay()`、`tweenNumber()`。
- 新增只限必要的：飘字（`+320 kcal`）、进度条光泽扫过。
- 所有 JS 驱动的动效都检查 `reduceMotion.matches`。

## Phase 3 等级方案（已确认并实现）

等级完全由客户端从历史数据重算，不改数据库，和 `evaluateAchievements` 一样逐日回放。 现有历史会立刻换算成经验，上线当天就有等级。

### 经验来源

| 来源 | XP | 说明 |
| --- | --- | --- |
| 日历星级 | 每颗星 10 | 复用 `dayStars`：记录、热量达标、蛋白吃够，每天最多 30 |
| 饮水达标 | 10 / 天 | 当天喝到饮水目标 |
| 称重 | 5 / 天 | 当天有体重记录 |
| 解锁勋章 | 铜 50 / 银 100 / 金 200 / 钻石 400 | 按 `state.achievements` 里已解锁的档位计算，档位 = 该系列第几个门槛 |

完美的一天最多 45 XP，下表按日均 35 XP 估算，不含勋章加成。

### 升级曲线

从 Lv L 升到 L+1 需要 `100 + 25 × (L - 1)` XP，越往后越慢，约一年到 Lv 30。

| 等级 | 累计 XP | 约需天数 | 称号 |
| --- | --- | --- | --- |
| Lv 1 | 0 | 0 | 新手村民 |
| Lv 5 | 550 | 16 | 见习冒险者 |
| Lv 10 | 1,800 | 51 | 青铜战士（铜色） |
| Lv 15 | 3,675 | 105 | 白银骑士（银色） |
| Lv 20 | 6,175 | 176 | 黄金勇者（金色） |
| Lv 30 | 13,050 | 373 | 钻石传奇（钻石色） |

不设等级上限。

### 展示与动效

- 日记页记分牌：加一个“Lv 12 青铜战士”等级 chip，下方是迷你经验条。
- 角色面板顶部：完整经验条，显示“1,240 / 1,500 XP”和今日已获得 XP。
- 侧边栏品牌标下：小号 Lv 徽标（手机底栏不显示）。
- 记一笔、喝水、称重让今日 XP 增加时，飘出 `+10 XP`，复用 `float-gain`。
- 升级时播放一次升级动画，复用勋章弹窗的光芒与 `stamp`，并弹出 award toast。
- 上次见过的等级存在 `localStorage`（只是 UI 提示），下次打开时发现升级也会补播。

### 实现

- 新模块 `level.js`：`totalXp()` 回放历史，`levelFor(xp)` 返回等级、本级进度、称号。
- 两个函数都加测试：曲线边界（100 XP 恰好 Lv 2）、各来源计分。

## 约束与风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 配色重做 | 现有颜色做过色盲与对比度校验，换深底后大部分失效 | Phase 0 逐个 token 重新校验：正文 ≥ 4.5:1，图形元素 ≥ 3:1 |
| 数据可读性 | 汇总页图表密集，装饰过多会干扰读数 | 图表内部保持克制，只改外框和配色 |
| 响应式溢出 | 边框和阴影变厚后，390px 下 flex 行更容易溢出 | 每个阶段按 CLAUDE.md 检查 390px 与 720px / 1100px 断点两侧，确认 `scrollWidth` 等于 `clientWidth` |
| 分段控件错位 | `.seg` 边框变厚会让滑块 thumb 对不齐 | 改完 `.seg` 后单独检查所有分段控件 |
| 动效过载 | 飘字、光泽、发光叠加后分散注意力 | 先复用现有 keyframes；JS 动效检查 `reduceMotion.matches` |
| 字体体积 | 中文装饰字体动辄数 MB | 不引入中文装饰字体，可选的拉丁衬线体用 Google Fonts 按需加载 |
