# MacroTracker 用户登录实施任务

2026-10-19。方案：[用户登录与多人使用](用户登陆.md)。配置：[部署配置](用户登陆-部署配置.md)。

## 方向调整

上一轮接入了 Auth0 Free 托管登录，因为免费版 Workers 每个请求只有 10 ms CPU，按 OWASP 强度做密码哈希会超限。
本轮按 Master Feiii 的决定改回本站自管用户名密码：密码以加盐 SHA-256 保存，朋友通过后台生成的邀请链接注册。
Auth0 流程、`jose` 依赖、Action 脚本、认证预检文档和相关测试已删除；迁移 0007 尚未上生产，直接在原文件中调整。

主任务只有完整验收后才勾选；子项用于区分代码完成与浏览器或线上验收。流程为 `AUTH-01 → DATA-01 → AUTH-02 → DATA-02 → UI-01 → ADMIN-01 → RULES-01 → RELEASE-01`。
